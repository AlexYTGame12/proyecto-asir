# proyecto-asir
Documentación del proyecto de PIMA

Proyecto ASIR -- Tienda
Se vende productos variados, como alimentos, bebidas, productos de limpieza, higiene y artículos para el hogar.
Tiene 5 trabajadores

Fallos informaticos:
1. Fallo en el ordenador de caja: el equipo se bloquea y no permite cobrar a los clientes.


2. Problemas de conexión a Internet: no funciona el acceso a Internet ni el pago con tarjeta.


3. Fallo en la impresora de tickets: no imprime los recibos de compra de los clientes.
